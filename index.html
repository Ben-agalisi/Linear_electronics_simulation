Dots are a visual cue: the number of electrons in the channel sets the current, and dot speed only hints at it. VDS is assumed already on.
The formula with your numbers:
What the symbols mean
VGS
Voltage between the Gate and the Source. This is the control knob.
ID
Drain current: the current flowing through the Drain.
IDSS
Drain current when VGS = 0 (gate shorted to source). A fixed value for the device.
VGS(off)
Gate voltage at which the channel pinches off and ID drops to zero. Also fixed for the device.
Depletion mode
Negative VGS pushes electrons out of the channel, so it narrows.
Enhancement mode
Positive VGS pulls extra electrons in, so the channel widens.
